# Habits Tracker — запуск и хранение данных

Frontend использует обычные HTML, CSS и JavaScript без сборщика.

## Запуск

1. Установи зависимости из корневого requirements.txt.
2. Из корня проекта запусти backend: uvicorn backend.main:app --reload.
3. Открой frontend/ через VS Code Live Server.
4. По умолчанию frontend обращается к API по адресу http://127.0.0.1:8000. При другом адресе измени API_BASE в frontend/auth.js.

## Авторизация

Регистрация: POST /registration

Тело запроса: { "username": "semen", "password": "example123" }

После успешной регистрации приложение возвращает пользователя на форму входа. Вход выполняется отдельным запросом: POST /login с тем же телом.

Оба маршрута возвращают JSON с ok: true. При занятом имени регистрации backend отвечает статусом 409, при неверном пароле входа — 401.

## Привычки и учёт времени

Сейчас backend содержит только регистрацию и проверку логина. Поэтому привычки, записи времени, суммарные минуты и настройки Pomodoro сохраняются в localStorage браузера отдельно для каждого вошедшего имени пользователя. Это позволяет пользоваться интерфейсом без дополнительных API-маршрутов и таблиц базы данных.

Данные хранятся на том устройстве и в том браузере, где их создали. Для синхронизации между устройствами в будущем понадобятся backend-маршруты и таблицы базы данных для привычек и записей времени.

## Возможности

- Создание, редактирование, поиск, отметка и удаление привычек.
- Pomodoro: пресеты 50/10 и 45/15, собственные интервалы и выбор количества подходов.
- Ручной учёт минут работы и отдыха по задачам.
- Автоматическое добавление завершённых интервалов Pomodoro к выбранной задаче.
- Сумма минут по каждой задаче и общий итог за всё время.
