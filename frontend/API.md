# Frontend и Backend API — Habits Tracker

Frontend расположен в папке \`frontend/\`. Он использует обычные HTML, CSS и JavaScript, без сборщика и дополнительных библиотек.

## Запуск

1. Запусти FastAPI на \`http://127.0.0.1:8000\`.
2. Открой папку \`frontend/\` через VS Code Live Server (обычно \`http://127.0.0.1:5500\`).
3. Введи адрес API в начале \`script.js\` и \`auth.js\`, если backend запущен не на \`http://127.0.0.1:8000\`.

В запросах авторизации используется \`credentials: "include"\`, потому что текущий Backend записывает JWT в cookie.

## Уже реализованные Backend-маршруты

### Регистрация

\`POST /register\`

Тело:

\`\`\`json
{
  "username": "semen",
  "password": "example123"
}
\`\`\`

Успешный ответ текущего Backend:

\`\`\`json
{
  "ok": true,
  "user_id": 1
}
\`\`\`

После регистрации Frontend автоматически вызывает вход, чтобы получить cookie авторизации.

### Вход

\`POST /login\`

Тело:

\`\`\`json
{
  "username": "semen",
  "password": "example123"
}
\`\`\`

Backend возвращает \`{"ok": true}\` и устанавливает cookie \`acces_cooke\`.

## Маршруты привычек, необходимые Frontend

В текущем \`backend/routers/routers.py\` маршруты привычек пока не реализованы. Ниже контракт, под который написан Frontend. Backend-код этим файлом не изменялся.

### Получить привычки

\`GET /habits\`

Рекомендуемый ответ:

\`\`\`json
[
  {
    "id": 1,
    "habitname": "Читать 20 минут",
    "description": "Перед сном",
    "category": "Обучение",
    "icon": "📚",
    "done": false,
    "user_id": 1
  }
]
\`\`\`

Допускается также обёртка \`{"habits": [...]}\`.

### Создать привычку

\`POST /habits/create\`

Тело соответствует текущей \`HabitSchema\`:

\`\`\`json
{
  "habitname": "Читать 20 минут",
  "description": "Перед сном",
  "category": "Обучение",
  "icon": "📚",
  "done": false
}
\`\`\`

Рекомендуемый ответ: созданный объект привычки с \`id\`.

### Изменить привычку

\`PUT /habits/{habit_id}\`

Тело:

\`\`\`json
{
  "habitname": "Читать 30 минут",
  "description": "Каждый вечер",
  "category": "Обучение",
  "icon": "📚"
}
\`\`\`

### Переключить статус выполнения

\`POST /habits/{habit_id}/toggle\`

Тело не требуется. Backend меняет \`done\` на противоположное значение и возвращает обновлённую привычку.

### Удалить привычку

\`DELETE /habits/{habit_id}\`

Удаляет привычку и возвращает \`{"ok": true}\` или статус \`204 No Content\`.

## Важные требования к Backend

- Каждая привычка должна быть привязана к авторизованному пользователю через \`user_id\`.
- Все маршруты \`/habits\` должны проверять JWT-cookie и не выдавать чужие привычки.
- Для запросов с cookie CORS должен разрешать точный адрес Frontend и \`allow_credentials=True\`. В текущем \`backend/main.py\` уже разрешён \`http://localhost:5500\` и \`http://127.0.0.1:5500\`.
- Не возвращай пароль или хеш пароля в API-ответах.
- Сейчас в модели есть \`habitname\`, \`description\`, \`category\`, \`icon\`, \`done\`; Frontend использует именно эти поля. Даты выполнения интерфейс не отправляет, потому что такого поля пока нет в модели.
- В текущем Backend нет маршрута выхода. Кнопка выхода очищает имя пользователя на Frontend; для полноценного завершения JWT-cookie добавь отдельный серверный endpoint, который удалит cookie.
